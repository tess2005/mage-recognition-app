# Image Recognition System 📸

This is an AI-powered web application that identifies objects in uploaded images. It was built using Python, Streamlit, and PyTorch.

## Features
- Upload images (JPG/PNG).
- Real-time object identification using a pre-trained ResNet model.
- Responsive web interface.

## Live Demo
You can access the live application here: https://mage-recognition-app-4vkbnisgv54cdjqbwjbs5y.streamlit.app

## How to run locally
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`
